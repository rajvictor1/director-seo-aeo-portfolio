# SITE IDENTITY
Hevo Data is a no-code ETL/ELT data integration platform. It helps data analysts,
RevOps teams, and small-to-mid-market data engineers build data pipelines from
SaaS apps, databases, and event streams into cloud data warehouses without writing
code. Key competitors include Fivetran, Airbyte, Stitch, Matillion, and Rivery.

Core facts:
- 150+ pre-built connectors (databases, SaaS apps, file storage, event streams)
- No-code pipeline setup with near-real-time sync
- Transparent, event-based pricing with a free tier
- dbt-based transformations built into the platform
- SOC 2, GDPR, CCPA, HIPAA, and DORA compliant
- Customer logos include ThoughtSpot, Icelandair, Postman, and Deliverr
